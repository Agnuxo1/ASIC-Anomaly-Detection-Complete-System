## Project scope

The declared research direction combines SHA-256 ASIC-derived deterministic features with CNN-based medical-image anomaly detection.

The repository was empty before this scope note. It currently contains no system implementation, clinical dataset, benchmark or validation receipt. The name describes the intended project, not an established completeness or performance claim.
